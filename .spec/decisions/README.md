# 决策记录（ADR）

为什么这样选、为什么不选别的，都记在这里。知识文档只写现状，不写决策过程。

## 怎么写

- 一个决策一个文件：`ADR-NNN-<英文短语>.md`，编号从 `001` 递增，不撞号。写完在下面的索引加一行。
- 开头格式：

  ```markdown
  # ADR-NNN：<一句话决策>

  状态：Draft
  日期：YYYY-MM-DD

  ## 背景
  面对什么问题。

  ## 决策
  定了什么。

  ## 替代方案与否决理由
  还考虑过什么、为什么不选。

  ## 影响
  这个决定带来什么约束、以后要注意什么。
  ```

- 状态取 `Draft`（还可能改）、`Accepted`（已定）、`Superseded`（被取代）。`Accepted` 之后不改写；要推翻就新写一条，把旧的状态改成 `Superseded（被 ADR-NNN 取代）`。
- 只记用户拍板的决定。
