# AI 出图

本技能只把已定的美术方向翻译成 prompt，核心是**风格一致**；不定调。方向由 [art-director](../art-director/SKILL.md) 定，基准是美术一页纸 `.spec/knowledge/art/README.md`。

## 靠三样东西保持一致

1. **风格锚**：一段 15–25 个词的固定英文短语，写在美术一页纸里，带版本号（如「风格锚 v1」）。每条 prompt 原样带上，不改写、不即兴加词。要变风格，走 art-director 定调，并把风格锚升一个版本。
2. **基准图库**：用户定稿的图放进 `Art/baseline/` 下，按 `ui/`、`character/`、`scene/`、`vfx/` 分。以后出图都拿它们当参考。
3. **出图记录**：每张基准图旁边放一份 `<图名>.prompt.md`，记：完整 prompt、负向、工具和模型版本、seed、参考了哪几张基准图。

美术一页纸里风格锚还是「待完善」时是**探索模式**：先和用户确认这次的风格假设，每张图标「风格未锁定，按假设 X 出图，仅探索」，把假设交回 art-director；探索图不进基准图库。

## 出图流程

1. **读**美术一页纸的风格锚（看版本号）、色板、反面清单。
2. **挑参考**：从基准图库挑 1–3 张。同一类优先（出界面就挑界面）；还没有这一类的，挑最能代表整体风格的。参考图会把它的背景、底座、角色一起带进新图，按下面「挑参考图」再筛一遍。
3. **写 prompt**（见下面 8 段），带上风格锚原文；整屏图和透明物件分开写（见下面「整屏图和透明物件分开写」）；参考图用出图工具自带的参考图功能传进去；参数沿用参考图出图记录里的（工具、模型版本、画幅、风格化强度、seed 思路）。要用 `lgui art cut` 拆的整页图，写之前先读 LGUI 的「art cut 对输入图的要求」（见下面「要拆的整页图」）。
4. **每页至少出 2 张**（一页 = 一张整屏图或一张要拆的整页图），说清每张差在哪：同一套 prompt 和参考图，常常一张对一张错，要拆的整页图用拆图结果判断哪张能用。批量出图时同时最多发 3 张请求；失败的隔一会儿重试，最多 3 次，重试记进出图记录，3 次还失败就停下，把报错原文告诉用户。逐张过四关：
   - **一致性关（第一关）**：和参考图并排比颜色、线条、光影、材质、比例，不像同一款游戏就不往下看。
   - **结构关**：手、对称装饰、透视这类 AI 常见硬伤。
   - **落地关**：能不能拆件、切九宫，缩到实际尺寸还看不看得清。
   - **合规关**：不复刻具体作品；AI 图默认只作概念、参考、垫图，直接进游戏要人工重制或过 [art-review](../art-review/SKILL.md)，并遵守商店对 AI 内容的申报要求。
5. **定稿入库**：用户定稿后，图放进 `Art/baseline/<类别>/`，旁边写好 `<图名>.prompt.md`。

## 整屏图和透明物件分开写

整屏图（效果图、背景、加载图）和透明底的物件（图标、道具、按钮和面板的零件）分开写 prompt，不共用同一段通用结尾：

- 给物件写的「透明底」一类要求，会把整屏图也带偏——出成透明底、画出假的棋盘格，或者一片黑底。
- 整屏图在末尾写明它是铺满画布的整屏背景、不透明、不要棋盘格；物件在末尾写明透明底、不要底座和背景。

## 挑参考图

参考图不只传风格，还会把它的背景、底座、角色带进新图：

- **出透明物件**：只挑透明底、没有底座的参考图（可以加一张材质样板），不拿不透明的整屏效果图当参考——它的背景会被画进来。
- **底座会传染**：参考图里的物件放在徽章、圆底这类底座上，新图的物件也会被画上底座；不要底座就换没有底座的参考，并在末尾写明「不要底座」。
- **角色会被照着画**：参考图里有不能出现在游戏里的角色（比如别家作品的截图），模型会照着画；选和它差得最远的那张，或者不传那张参考。

## 要拆的整页图

要用 `lgui art cut` 拆成小图的整页图，对输入图的要求以 LGUI 仓库 `plugin/references/ui-spec.md` 第 5 节「art cut 对输入图的要求」为准（https://github.com/LumioGames/LGUI/blob/main/plugin/references/ui-spec.md ，本地在 LGUI 插件目录的 `references/ui-spec.md`）。那一节由 LGUI 维护，这里不复述；写 prompt 前先读，按它的要求写进末尾。

## 防跑偏

用户要求时，把某一类的基准图按时间排开看，找出从哪一张开始偏离风格锚和最早的定稿；之后出图只拿偏之前的那些做参考，偏了的告诉用户要不要撤出基准图库。

## prompt 怎么写（8 段）

中文和用户说意图，prompt 用英文：

1. **主体**：具体的名词短语，不写 "a character"，写 "young herbalist girl, twin braids, oversized satchel"。
2. **风格锚**：美术一页纸里的原文，带版本。
3. **媒介**：game concept art / flat UI icon / isometric environment render。
4. **构图镜头**：图标一律正面平视。
5. **光影**：每一类固定一种写法。
6. **色板**：HEX 色值 + limited palette。
7. **负向**：photo-realistic, text, watermark，加上反面清单直译。负向不能省：游戏资产要干净的剪影和低噪的底。
8. **参数**：画幅、风格化强度、seed，按工具的写法。

```text
[主体], [风格锚 vN 原文], [媒介], [构图镜头], [光影], [色板 HEX + limited palette]
负向: photo-realistic, text, watermark, [反面清单直译]
参数: [画幅] [风格化强度] [seed]
```

**工具参数**：各工具的参考图功能和参数写法记在美术细节文档（如 `.spec/knowledge/art/prompts.md`，第一次用某个工具时建），不在本技能里补。

## 注意

- **prompt 不是规范**：好用的出图词要进规范，先经 art-director 定调，再写进美术一页纸。
- **探索图不是定稿**：拿探索图当既成风格，等于跳过定调。
- **风格一致 ≠ 角色一致**：同一个角色多次出现，另外用角色参考图保持一致。

## 验证

- 带了哪一版风格锚、参考了哪几张基准图，都说清了。
- 每条 prompt 有负向和参数；同一批参数一致；整屏图和透明物件没有共用结尾。
- 每页至少出了 2 张；重试过的记进了出图记录。
- 四关结论都给了，一致性关排在第一。
