## 后果

- 模块之间的依赖受 `.spec/rules/project.md` 约束，跨模块的新东西放哪先查 `project-structure.md`。
- 加减模块、换技术路线、改发布目标，都要新写一条 ADR 取代本条，并同步改模块 README 和规范。
