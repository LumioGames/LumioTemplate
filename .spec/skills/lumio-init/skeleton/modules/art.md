# Art（美术源文件）

{{暂定名}}的美术源文件。风格怎么定、规范是什么，在 `.spec/knowledge/art/README.md`（美术一页纸）；这里只放文件。

## 放什么

- 风格探索：草图、情绪板、反例板。
- 参考图：注明来源和「取什么 / 不取什么」。
- 出图提示词：AI 出图用的提示词和参数（art-prompt 技能产出）。
- 可编辑源文件：PSD、Figma 导出、Spine、Blender 等。
- 资产清单：要做哪些资产、谁做、做到哪了。

## 目录

> 待完善：定美术方向时补。默认按用途分：`explore/`（风格探索）、`reference/`（参考图）、`prompts/`（出图提示词）、`source/`（可编辑源文件），资产清单放 `assets.md`。

## 依赖

- 不被产品代码直接引用。游戏里用的图片、模型导出后放进客户端工程。

## 不准做什么

- 不放构建产物，放 `Builds/`。
- 参考图没有授权的只能内部参考，不能直接用进游戏。
- 大文件（视频、高分辨率源文件）先和用户商量要不要用 Git LFS，不直接塞进仓库。
